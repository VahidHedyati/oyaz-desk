# OyazDesk - Enterprise Remote Desktop Client
**نسخه سازمانی کلاینت ریموت دسکتاپ اختصاصی شرکت جهان اروم ایاز**

---

### مشخصات و زیرساخت نسخه سازمانی:
* **توسعه‌دهنده:** واحد فناوری اطلاعات شرکت جهان اروم ایاز (Jahan Orum Oyaz IT Department)
* **زیرساخت شبکه:** ارتباط مستقیم محلی (LAN P2P) و اتصال اختصاصی به سرور داخلی کارخانه
* **امنیت:** دارای گواهی دیجیتال اختصاصی ریشه (Root CA) معتبر تا سال ۲۰۳۶
* **استقلال کامل:** فاقد هرگونه ترافیک خارجی، بدون وابستگی ابری و مسدودسازی کامل آپدیت‌های عمومی اینترنتی

### ویژگی‌ها:
- پکیج نصبی یکپارچه و مستقل (Standalone All-in-One Installer)
- تنظیم و پیکربندی خودکار قوانین فایروال ویندوز جهت اتصال پرسرعت P2P
- بهینه‌سازی رابط کاربری و حذف گزینه‌های غیرضروری سازمانی
